# PINWHEELS site

Static one-page site for Pinwheels. No build step, no framework, no dependencies.
Edit the files, push, and GitHub Pages redeploys in about a minute.

```
index.html      the whole page
style.css       all the styling
assets/         portrait, star SVGs, favicon, brand font
```

## Editing

**Links (Spotify / Apple / SoundCloud / IG)**: the `<p class="nav">` block in `index.html`.

There is no track list on purpose: the nav points at the streaming profiles, so releasing
music needs no change here.

**Colors**: `style.css`. Link color is `#9765d0`, search and replace it.

**The wordmark** is inline SVG at the top of `index.html`: vector outlines plus SVG lighting
filters (a blurred copy of the letters is used as a height map, then lit) over a reflection
gradient. It was generated by `lockup.py` / `mat.py`, which are not in this repo. Editing the
text means regenerating it, so treat the SVG as a logo file rather than as markup.

**Portrait**: replace `assets/portrait.jpg` (square, 800x800).

**Star dividers / frame**: `assets/stars-rule.svg` and `assets/stars-frame.svg`. The star
shapes are the pointed-star glyphs from DejaVu Sans traced to paths, with a chrome gradient.

**Background stars** are generated by the small script at the bottom of `index.html`.
Change the `48` to have more or fewer.

## Deploying (GitHub Pages)

`.github/workflows/pages.yml` deploys on every push to `main`. Commit, push, wait a
minute, refresh. Live at https://pinwheels.online

The `CNAME` file is what pins the domain. Do not delete it. If styles look stale after a
deploy, bump the `?v=` number on the stylesheet link in `index.html`; Pages caches CSS for
10 minutes.

## Local preview

Run `python3 -m http.server` in this folder and open `http://localhost:8000`.
